# Assets

The game ships with **no external art or audio**: every portrait, background, persona silhouette, Echo,
effect and sound is generated procedurally in code. That keeps the repo self-contained and free of
copyrighted material.

To use your own images, drop files here and register them in `manifest.json`. See
[`docs/ASSETS.md`](../docs/ASSETS.md) for keys, sizes and legal notes. Files in these folders are
git-ignored by default so you never accidentally commit material you don't own.
